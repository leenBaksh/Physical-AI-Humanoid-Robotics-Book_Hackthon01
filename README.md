# Physical AI & Humanoid Robotics Book

This repository contains the source code for "Physical AI & Humanoid Robotics Book", a comprehensive guide to Physical AI fundamentals for humanoid robotics.

## About This Book

This book is designed for students and developers entering Physical AI with Python and basic AI knowledge. It covers:

- **Chapter 1**: ROS 2 Core – Learn about nodes, topics, and services
- **Chapter 2**: The AI-ROS Bridge – Connect Python-based AI agents to ROS 2
- **Chapter 3**: URDF Interpretation and Kinematics – Understand robot structure

Each chapter includes hands-on tutorials and practical exercises to ensure you can create ROS 2 nodes, connect AI agents, and interpret robot models.

## Prerequisites

Before starting this book, ensure you have:

- Basic Python knowledge
- Ubuntu 22.04 LTS or equivalent Linux distribution
- ROS 2 Humble Hawksbill installed
- Node.js 16.x or higher (for documentation)

## Getting Started

1. Install ROS 2 Humble Hawksbill by following the [official installation guide](https://docs.ros.org/en/humble/Installation.html)
2. Install Node.js dependencies:
   ```bash
   npm install
   ```
3. Start the documentation server:
   ```bash
   npm start
   ```

## Documentation Structure

The documentation is organized as follows:

- `docs/tutorial/`: Main tutorial content for each chapter
- `docs/getting-started/`: Setup and installation guides
- `assets/code-examples/`: Code examples referenced in the book
- `assets/diagrams/`: Diagrams and visual aids
