# Chapter 1: ROS 2 Core – Nodes, Topics, & Services

Welcome to the fundamentals of ROS 2! In this chapter, you'll learn about the core concepts that make up the Robot Operating System 2 (ROS 2), including nodes, topics, and services.

## What You'll Learn

By the end of this chapter, you will:
- Understand what ROS 2 nodes are and how they function
- Learn about the publisher-subscriber communication pattern using topics
- Explore service-based communication between nodes
- Create your first ROS 2 nodes that communicate with each other

## Prerequisites

Before starting this chapter, ensure you have:
- Basic Python knowledge
- ROS 2 Humble Hawksbill installed
- rclpy library installed

Let's begin by exploring the foundational concept of ROS 2: **Nodes**.
