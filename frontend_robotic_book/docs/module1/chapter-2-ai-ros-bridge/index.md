# Chapter 2: The AI-ROS Bridge (rclpy)

In this chapter, you'll learn how to connect Python-based AI agents to ROS 2 control systems using rclpy, the Python client library for ROS 2. This bridge enables AI decision-making to control robotic systems.

## What You'll Learn

By the end of this chapter, you will:
- Understand how to use rclpy to integrate Python logic with ROS 2
- Design message interfaces for agent-robot communication
- Build a simple AI agent node that processes sensor data
- Create communication patterns between AI agents and robot systems

## Prerequisites

Before starting this chapter, ensure you have:
- Completed Chapter 1: ROS 2 Core concepts
- Basic understanding of Python programming
- ROS 2 Humble Hawksbill and rclpy installed
- Basic knowledge of AI/decision-making algorithms
