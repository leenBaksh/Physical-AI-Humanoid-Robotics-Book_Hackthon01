# Module 2: The Digital Twin (Gazebo & Unity)

Welcome to Module 2 of the Physical AI & Humanoid Robotics book. This module focuses on physics simulation and sensor modeling for humanoid robots using Gazebo and Unity.

## Overview

In this module, you'll learn about creating digital twins of humanoid robots using simulation environments. We'll cover:

- **Gazebo Fundamentals**: Simulating physics, gravity, and collisions
- **Sensor Simulation**: Modeling LiDAR, Depth Cameras, and IMUs in Gazebo
- **High-Fidelity HRI**: Introduction to human-robot interaction in Unity

## Prerequisites

Before starting this module, you should have completed Module 1 and have a basic understanding of ROS 2 concepts.

## Learning Objectives

By the end of this module, you will be able to:

- Create realistic physics simulations in Gazebo
- Configure and simulate various sensor types in Gazebo
- Understand human-robot interaction concepts in Unity
- Apply simulation techniques to humanoid robotics applications
