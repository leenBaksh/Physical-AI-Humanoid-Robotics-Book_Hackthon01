# Data Model: Backend API & Frontend Integration

## Entity: ChatMessage
**Description**: Represents a single message in a conversation

### Fields
- `id` (str): Unique identifier for the message
- `session_id` (str): ID of the conversation session this message belongs to
- `content` (str): The actual message text
- `sender_type` (str): Type of sender ("user" or "agent")
- `timestamp` (datetime): When the message was created
- `metadata` (Dict[str, Any]): Additional metadata about the message

### Relationships
- Belongs to a ConversationSession
- Part of a sequence in conversation history

### Validation Rules
- Content must not be empty
- Sender_type must be either "user" or "agent"
- Timestamp must be in the past or present
- Session_id must be valid

## Entity: ConversationSession
**Description**: Represents a user's conversation history with a unique session ID

### Fields
- `session_id` (str): Unique identifier for the conversation session
- `created_at` (datetime): When the session was created
- `updated_at` (datetime): When the session was last updated
- `messages` (List[ChatMessage]): List of messages in the conversation
- `metadata` (Dict[str, Any]): Additional session metadata

### Relationships
- Contains multiple ChatMessage entities
- Maintains conversation context across multiple exchanges

### Validation Rules
- Session_id must be unique
- Created_at must be before updated_at
- Messages list must not exceed maximum size
- Session must have valid creation timestamp

## Entity: ChatRequest
**Description**: Represents a request sent to the chat API

### Fields
- `message` (str): The user's message content
- `session_id` (str): ID of the conversation session
- `timestamp` (datetime): When the request was made
- `options` (Dict[str, Any]): Additional options for the request (e.g., top_k, temperature)

### Relationships
- Processed by the Chat API endpoint
- Creates a new ChatMessage in the conversation

### Validation Rules
- Message must not be empty
- Session_id must be valid
- Options must be properly formatted

## Entity: ChatResponse
**Description**: Represents the system's response to a chat request

### Fields
- `answer` (str): The agent's response text
- `citations` (List[Dict[str, str]]): List of sources used in the response
- `session_id` (str): ID of the conversation session
- `timestamp` (datetime): When the response was generated
- `metadata` (Dict[str, Any]): Additional response metadata

### Relationships
- Generated by the BookAgent through the API
- Associated with a ChatRequest
- Creates a new ChatMessage in the conversation

### Validation Rules
- Answer must not be empty
- Citations must be properly formatted
- Session_id must match the request
