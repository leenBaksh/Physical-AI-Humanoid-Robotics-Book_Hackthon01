# Data Model: OpenAI Agent with RAG Capabilities

## Entity: RetrievedChunk
**Description**: Represents a chunk of content retrieved from the Qdrant collection

### Fields
- `content` (str): The actual text content of the chunk
- `source_url` (str): URL of the original source page
- `score` (float): Relevance score from the similarity search
- `chunk_index` (int): Index position of the chunk in the original document
- `metadata` (Dict[str, Any]): Additional metadata about the content

### Relationships
- Retrieved by BookRetriever from Qdrant collection
- Used as context by BookAgent

### Validation Rules
- Content must not be empty
- Score must be between 0.0 and 1.0
- Source URL must be valid

## Entity: AgentResponse
**Description**: Represents a response generated by the BookAgent

### Fields
- `answer` (str): The generated answer to the user's question
- `citations` (List[Dict[str, str]]): List of sources used in the response
- `confidence` (float): Agent's confidence in the response (0.0-1.0)
- `retrieved_chunks_used` (List[RetrievedChunk]): Chunks that were used to generate the response
- `timestamp` (datetime): When the response was generated

### Relationships
- Generated by BookAgent in response to a user query
- Contains references to the RetrievedChunks used
- Part of a conversation session

### Validation Rules
- Answer must not be empty
- Citations must be properly formatted
- Confidence must be between 0.0 and 1.0

## Entity: ConversationContext
**Description**: Represents the context of a conversation session

### Fields
- `session_id` (str): Unique identifier for the conversation session
- `history` (List[Dict[str, str]]): List of previous exchanges in the conversation
- `current_context` (List[RetrievedChunk]): Current context chunks being used
- `last_query` (str): The most recent user query
- `last_response` (AgentResponse): The most recent agent response

### Relationships
- Contains multiple user queries and agent responses
- Maintains context for follow-up questions
- Associated with a specific user session

### Validation Rules
- Session ID must be unique
- History must not exceed maximum length
- Context chunks must be relevant to the conversation

## Entity: QueryRequest
**Description**: Represents a user's query request to the agent

### Fields
- `query` (str): The user's natural language query
- `session_id` (str): ID of the session this query belongs to
- `timestamp` (datetime): When the query was submitted
- `top_k` (int): Number of chunks to retrieve (default: 5)

### Relationships
- Submitted by a user to the BookAgent
- Processed by BookRetriever to get context
- Results in an AgentResponse

### Validation Rules
- Query must not be empty
- Session ID must be valid
- Top-k must be positive

## Entity: RetrievalResult
**Description**: Represents the result of a retrieval operation

### Fields
- `query` (str): The original query that was processed
- `retrieved_chunks` (List[RetrievedChunk]): List of chunks retrieved from Qdrant
- `execution_time` (float): Time taken to perform the retrieval
- `relevance_threshold` (float): Minimum relevance score for inclusion

### Relationships
- Generated by BookRetriever in response to a QueryRequest
- Used as input to BookAgent for context
- Contains RetrievedChunks that inform the AgentResponse

### Validation Rules
- Retrieved chunks must meet relevance threshold
- Execution time must be reasonable (e.g., under 5 seconds)
