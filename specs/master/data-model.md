# Data Model: Physical AI & Humanoid Robotics Book with RAG Chatbot

## Book Content Structure

### Book

- **title**: String (e.g., "Physical AI & Humanoid Robotics")
- **description**: String (overview of the book content)
- **modules**: Array of Module objects
- **authors**: Array of String (author names)
- **version**: String (book version)
- **last_updated**: Date (timestamp of last content update)

### Module

- **name**: String (e.g., "Module 1: ROS 2 Fundamentals")
- **description**: String (overview of module content)
- **chapters**: Array of Chapter objects
- **prerequisites**: Array of String (what student should know before starting)
- **learning_outcomes**: Array of String (what student will learn)

### Chapter

- **title**: String (e.g., "ROS 2 Core – Nodes, Topics, & Services")
- **description**: String (overview of chapter content)
- **sections**: Array of Section objects
- **files**: Array of String (file paths for chapter content)
- **prerequisites**: Array of String (what reader should know for this chapter)
- **learning_objectives**: Array of String (what reader will learn in this chapter)

### Section

- **title**: String (e.g., "Understanding Nodes in ROS 2")
- **content**: String (path to content file)
- **prerequisites**: Array of String (what reader should know)
- **learning_objectives**: Array of String (what reader will learn)
- **examples**: Array of Example objects (code/config examples)

### Example

- **title**: String (e.g., "Basic Publisher Node")
- **type**: String ("code-snippet", "configuration", "diagram")
- **language**: String (e.g., "python", "bash", "yaml", "xml")
- **content**: String (the actual example content)
- **explanation**: String (what the example demonstrates)

## RAG System Data

### DocumentChunk

- **id**: String (unique identifier for the chunk)
- **content**: String (the text content of the chunk)
- **metadata**: Object (source file, section, chapter, module information)
- **embedding**: Array of Number (vector embedding of the content)
- **source_file**: String (path to the original source file)
- **page_number**: Number (if applicable)
- **section_title**: String (title of the section this chunk belongs to)

### ChatSession

- **id**: String (unique session identifier)
- **user_id**: String (identifier for the user, if available)
- **created_at**: Date (timestamp when session was created)
- **last_activity**: Date (timestamp of last interaction)
- **messages**: Array of Message objects
- **metadata**: Object (additional session information)

### Message

- **id**: String (unique message identifier)
- **role**: String ("user" or "assistant")
- **content**: String (the message text)
- **timestamp**: Date (when the message was created)
- **context_used**: Array of String (document chunks referenced in the response)
- **selected_text**: String (text selected by user for context-specific Q&A)

## Content Management

### ContentUpdate

- **id**: String (unique update identifier)
- **file_path**: String (path to the updated file)
- **change_type**: String ("create", "update", "delete")
- **old_content**: String (previous content, if applicable)
- **new_content**: String (new content, if applicable)
- **timestamp**: Date (when the update occurred)
- **triggered_reindex**: Boolean (whether this update triggered a reindex operation)

### RAGIndex

- **id**: String (unique index identifier)
- **version**: String (version of the index)
- **created_at**: Date (when the index was created)
- **last_updated**: Date (when the index was last updated)
- **document_count**: Number (number of documents in the index)
- **embedding_model**: String (name of the model used for embeddings)
- **status**: String ("ready", "updating", "error")

## User Interaction

### UserQuery

- **id**: String (unique query identifier)
- **session_id**: String (associated chat session)
- **query_text**: String (the original query from the user)
- **processed_query**: String (query after processing)
- **timestamp**: Date (when the query was made)
- **retrieved_chunks**: Array of String (IDs of retrieved document chunks)
- **response**: String (the response generated by the system)
- **feedback**: Object (user feedback on the response quality)

### UserFeedback

- **id**: String (unique feedback identifier)
- **query_id**: String (associated query)
- **rating**: Number (1-5 star rating)
- **comment**: String (optional user comment)
- **timestamp**: Date (when feedback was provided)
- **helpful**: Boolean (whether the response was helpful)
